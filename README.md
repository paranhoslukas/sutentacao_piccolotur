# Coleta de informacoes da maquina

## Como executar o script

1. Abra o Prompt de Comando no Windows.
2. Navegue ate a pasta do projeto e execute o BAT abaixo:

```bat
public\\coletar_info_maquina.bat
```

## Onde o TXT e salvo

O arquivo de saida `machine_info.txt` e criado no mesmo diretorio do BAT:

```
public\\machine_info.txt
```

O conteudo do TXT segue o formato:

```
serial=...
hostname=...
mac_lan=...
mac_wifi=...
```
